# 📄 Personal Resume Website

A clean, modern, and responsive personal resume website built using **HTML5 and CSS3**. This project showcases my education, technical skills, internship experience, projects, certifications, achievements, and professional interests.

## 🌐 Live Website

🔗 **[View My Resume](https://personal-resume-black.vercel.app/)**

## 👨‍💻 About the Project

This is my personal online resume designed to present my academic background, technical skills, practical experience, and projects in a simple and professional format.

The website is completely built using **HTML and CSS**, without any frontend framework, making it lightweight, fast, and easy to maintain.

```bash

```

Navigate to the project directory:

```bash

```

Then open:

